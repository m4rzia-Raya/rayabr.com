Sobre este arquivo

Leia-me

  • ALOCADOR — reproduz o Projecao_Carteiras_v1.xlsx no navegador, com as mesmas abas, seletores (Período / Modo / Base / Tx ADM), mapas de calor e janelas. Aba Evolução Futura removida por decisão de 05/08/2026.
  • Dados gerados pelo motor v5 —; probabilidades dos cenários lidas da planilha: —. Para atualizar após mudar carteiras ou cenário, rode o Recalcular.bat (o passo 4 regenera os dados deste HTML) e dê F5.
  • Os pesos são editáveis na tela Carteiras e recalculam todas as telas em tempo real. O botão Atualizar do Excel relê os pesos direto do Projecao_Carteiras_v1.xlsx (ou Carteiras.xlsx) da pasta do projeto — escolha o arquivo e tudo recalcula (requer internet só na primeira vez, para carregar o leitor de Excel).
  • Para mudar os CENÁRIOS (inputs macro: Selic, inflação, câmbio, prêmios, bolsa) é preciso rodar o motor Python (motor_py) e regenerar este arquivo — os retornos futuros mensais estão embutidos aqui (t=0..121; após o mês 121 a taxa é constante no LTCA, verificado no motor, o que permite os períodos de 20a/50a/100a).
  • Fórmulas idênticas às do Excel: bases Nominal / Real (deflacionada) / % CDI; modos Anualizado e Acumulado; VaR com Z=1,6415 e desvio populacional; piores janelas acumuladas (não anualizadas). Motor de cálculo validado contra o pipeline Python: 29.233 comparações, 0 divergências.
  • Tx ADM é só informativa (decisão 05/08): o valor é definido como input do motor antes de gerar este arquivo (local do input a definir) e aplicado como (1+r)/(1+adm)−1 no anualizado e (1+r)/(1+adm)^anos−1 no acumulado.
  • Fonte histórica: Historico_Mensal.xlsx × 28 classes de ativo. Retornos brutos, sem custos de transação ou impostos (Tx ADM informativa, nota de rodapé das tabelas).
